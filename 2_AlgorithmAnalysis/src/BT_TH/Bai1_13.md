# Bài tập 1.4.13: Phân tích bộ nhớ đối tượng (Java 64-bit Architecture)

Quy ước mô hình bộ nhớ chuẩn theo giáo trình *Algorithms, 4th Edition* (Robert Sedgewick, Kevin Wayne):
- **Object overhead:** 16 bytes.
- **Array overhead:** 24 bytes (16 bytes object overhead + 4 bytes length + 4 bytes padding).
- **Tham chiếu đối tượng (Reference):** 8 bytes.
- **Kiểu nguyên thủy:** `int` (4 bytes), `double` (8 bytes).
- **Padding:** Kích thước của mỗi đối tượng luôn được làm tròn lên bội số của 8 bytes.

## 1. Bảng tổng hợp chi phí bộ nhớ

| :--- | :--- | :---: | :---: |
| **a. Accumulator** | 16B (overhead) + 8B (`sum`) + 4B (`count`) | 4B | **32 bytes** |
| **b. Transaction** | 16B (overhead) + 8B (`who`) + 8B (`when`) + 8B (`amount`) | 0B | **40 bytes** |
| **c. FixedCapacityStackOfStrings** | • Object Stack: 16B + 8B (`a[]`) + 4B (`n`) + 4B padding = 32B<br>• Mảng `String[C]`: 24B (array overhead) + $8C$ bytes | 0B | **$(56 + 8C)$ bytes** |
| **d. Point2D** | 16B (overhead) + 8B (`x`) + 8B (`y`) | 0B | **32 bytes** |
| **e. Interval1D** | 16B (overhead) + 8B (`min`) + 8B (`max`) | 0B | **32 bytes** |
| **f. Interval2D** | 16B (overhead) + 8B (`x`) + 8B (`y`) *(chưa gồm đối tượng con)*<br>*(Nếu tính cả 2 đối tượng con `Interval1D`)* | 0B<br>— | **32 bytes**<br>**96 bytes** |
| **g. Double** | 16B (overhead) + 8B (`value`) | 0B | **24 bytes** |

## 2. Chi tiết từng trường hợp

### a. `Accumulator`
- **Biến thành viên:** `double sum; int count;`
- **Phân bổ:** 16 (overhead) + 8 (`double`) + 4 (`int`) = 28 bytes.
- **Padding:** Cần thêm 4 bytes để thành 32 (bội số của 8).
- **Kết luận:** **32 bytes**.

### b. `Transaction`
- **Biến thành viên:** `String who; Date when; double amount;`
- **Phân bổ:** 16 (overhead) + 8 (ref `who`) + 8 (ref `when`) + 8 (`double amount`) = 40 bytes.
- **Padding:** 0 bytes (đã chia hết cho 8).
- **Kết luận:** **40 bytes** *(không tính vùng nhớ của chuỗi String và Date bên ngoài)*.

### c. `FixedCapacityStackOfStrings` (mảng dung lượng $C$, $N$ phần tử)
- **Bản thân đối tượng Stack:**
    - 16 (overhead) + 8 (ref mảng `a[]`) + 4 (`int n`) + 4 (padding) = 32 bytes.
- **Đối tượng mảng `String[C]`:**
    - 24 (array overhead) + $8 \times C$ (mỗi phần tử là một tham chiếu 8 bytes) = $(24 + 8C)$ bytes.
- **Kết luận:** $32 + (24 + 8C) =$ **$(56 + 8C)$ bytes**.

### d. `Point2D`
- **Biến thành viên:** `double x; double y;`
- **Phân bổ:** 16 (overhead) + 8 (`double x`) + 8 (`double y`) = 32 bytes.
- **Padding:** 0 bytes.
- **Kết luận:** **32 bytes**.

### e. `Interval1D`
- **Biến thành viên:** `double min; double max;`
- **Phân bổ:** 16 (overhead) + 8 (`double min`) + 8 (`double max`) = 32 bytes.
- **Padding:** 0 bytes.
- **Kết luận:** **32 bytes**.

### f. `Interval2D`
- **Biến thành viên:** `Interval1D x; Interval1D y;`
- **Bản thân đối tượng `Interval2D`:**
    - 16 (overhead) + 8 (ref `x`) + 8 (ref `y`) = **32 bytes**.
- **Nếu tính cả 2 đối tượng `Interval1D` độc lập bên ngoài:**
    - $32 + (2 \times 32) =$ **96 bytes**.

### g. `Double` (Wrapper Class)
- **Biến thành viên:** `double value;`
- **Phân bổ:** 16 (overhead) + 8 (`double value`) = 24 bytes.
- **Padding:** 0 bytes.
- **Kết luận:** **24 bytes**.
